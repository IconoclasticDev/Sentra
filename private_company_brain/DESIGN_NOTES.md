# Ideathon demo notes

## 120-second flow
1. Open Company Brain. Start with Maya (CEO).
2. Say: “A normal RAG system would find documents. Our system reconstructs organizational memory.”
3. Ask `Why was Project Orion delayed?` and show the causal timeline.
4. Ask `What changed in Orion between March and September?` and show temporal memory.
5. Ask `Who has the most experience with Orion's inference architecture?` and show evidence-backed people ranking.
6. Switch to Rhea (Intern). Ask the same Orion question. The answer deliberately withholds high-clearance security details.
7. End on: “We don't search the company's documents. We build a private intelligence layer that remembers the company.”

## Judges' conceptual hooks
- Private-by-design / customer-controlled deployment.
- Model-agnostic architecture.
- Organizational graph + temporal memory + decision memory.
- Permission-aware retrieval and reasoning.
- Same memory substrate usable by employees and AI agents.
